## ✨ 三大核心功能

### 🗺️ 批量地址 → 经纬度（正向地理编码）

Excel 丢一堆地址进去，一键全部跑出坐标，自动写回原表。

- ✅ 几千到几万行批量跑，不卡死
- ✅ 高德 + 百度双引擎，**高德额度用完自动切百度**，不用手动换 Key
- ✅ 本地 SQLite 缓存，**查过的地址永久存，第二次查秒出不耗额度**
- ✅ 区县漂移**自动标黄**，问题行一眼锁定
- ✅ 跑完自动拆 7 列结构化地址：省 / 市 / 区县 / 街道 / 道路 / 门牌 / 小区

### 📍 批量经纬度 → 标准地址（逆向地理编码）

反过来用！手里有 GPS 坐标？批量反查完整标准地址。

- ✅ 同样批量处理，同样写回 Excel
- ✅ 同样双引擎自动切换 + 本地缓存
- ✅ 输出完整结构化地址（省 / 市 / 区 / 乡镇 / 街道），做台账直接用

### 📡 POI 网格化地理信息采集

地图上框一个范围，工具自动按格子遍历，把区域内所有 POI 的**名称 + 坐标**全抓下来。

- ✅ 网格化自动遍历，不用手动一个个点
- ✅ 并发采集，速度快
- ✅ 自动去重（空间索引，同一个 POI 不重复抓）
- ✅ 关键词自动扩展（配置大模型后，"学校"自动展开大学 / 学院 / 中学 / 小学…）
- ✅ 结果直接导出 Excel

**适用场景**：通信覆盖分析 · 选址调研 · 商圈分析 · 设施普查

## 📋 Excel 格式约定

使用 `Standard_Address_Template.xlsx` 模板，列说明：

| 列号 | 字段 | 必填 | 说明 |
| --- | --- | --- | --- |
| 1 | 序号 | 推荐 | 任意编号 |
| 2 | 省 | 可选 | 如「云南省」 |
| 3 | 市 | 可选 | 如「曲靖市」 |
| 4 | 区县 | 可选 | 参与查询拼接与漂移比对 |
| 5 | 地址 1 | **必填** | 主地址 |
| 6 | 地址 2 | 选填 | 地址 1 异常时的备用地址 |
| 7-8 | GCJ-02 经纬度 | 输出 | 正向编码结果 |
| 9-10 | WGS-84 经纬度 | 输出 | 坐标互转结果 |
| 11 | 标准地址 | 输出 | 标准化地址（漂移时标注） |

## ❓ 常见问题

**Q：提示 Key 额度超限？**
A：工具支持高德 / 百度双引擎自动切换，一个引擎额度用完会自动切到另一个；也可以在「API 密钥配置」中替换为新申请的 Key。

**Q：什么是"漂移"？为什么标黄？**
A：输入地址的省 / 市 / 区县与返回结果跨行政区不一致时，判定为疑似漂移并标黄，便于人工复核；这类地址建议补充更详细的街道 / 门牌后重试。

**Q：导出的坐标是哪个坐标系？**
A：正向编码先输出 GCJ-02（高德 / 百度国内系），工具内置互转能力，可按需转换为 WGS-84；BD-09 与 GCJ-02 / WGS-84 的互转在坐标转换模块中单独选择。

**Q：查过的地址会重复消耗额度吗？**
A：不会。已成功查询的地址进入本地缓存，再次查询直接读缓存返回，不发起网络请求。

**Q：模板列可以自己加吗？**
A：第 5 列（地址 1）为必填，其余列按模板约定填写；多余列不会影响批量处理，但建议沿用模板列顺序以便结果自动写回。

**Q：精度等级是什么意思？**
A：工具按返回结果匹配到的行政区划级别（省 / 市 / 区县 / 街道 / 门牌）给出评分，级别越细代表定位越具体，可在结果列中筛选高分记录。
