# 地址坐标转换工具（AddressMap Tool）

基于高德地图与百度地图开放 API 的地址坐标转换桌面工具。支持单条查询与 Excel 批量正向/逆向地理编码、坐标系互转（GCJ-02 / WGS-84 / BD-09）、POI 兴趣点采集，内置地址清洗、智能去重与**行政区划漂移检测**（异常结果自动标黄）。

## ✨ 功能特性

- **单条地址查询**：高德为主数据源，失败自动降级百度，结果含精度等级与坐标
- **批量正向编码**：Excel 导入导出，自动清洗、智能合并（地址1+地址2）、地址去重、异常行重处理
- **批量逆向编码**：经纬度批量转结构化地址（省/市/区/乡镇/街道）
- **坐标转换**：GCJ-02 ↔ WGS-84 ↔ BD-09 互转，支持单条与批量
- **POI 采集**：关键字搜索 / 周边搜索，关键词自动扩展，高德+百度双源
- **漂移检测**：比对输入与结果的省/市/区县，跨区县结果自动标黄并标注"疑似漂移"
- **精度评分**：对返回结果按行政区划级别评分，便于筛选可靠数据
- **本地缓存**：重复地址秒回，降低 API 配额消耗
- **在线更新**：内置版本检测与在线升级通道

## 📦 环境要求

- Windows / macOS / Linux（GUI 基于 tkinter）
- Python 3.8+
- 依赖：`openpyxl`、`Pillow`（地图预览可选）

```bash
pip install openpyxl Pillow
```

## 🚀 快速开始

1. **申请密钥**
   - 高德开放平台：创建应用，开通「Web服务」API（地理/逆地理编码、POI 搜索）
   - 百度地图开放平台：创建应用，获取服务端 AK（浏览器端类型）
2. **启动程序**

   ```bash
   python addressmap_tool_v2.8.43.py
   ```

3. **配置密钥**：首次启动在「API密钥配置」页填写高德 Key 与百度 AK，保存后写入本地 `addr_config.json`（该文件已被 .gitignore 排除，不会提交到仓库）

4. **导入数据**：下载/使用 `Standard_Address_Template.xlsx` 模板，填写待处理地址，执行批量转换

## 📋 Excel 格式约定

模板列（自第 1 列起）：

| 列号 | 字段 | 说明 |
| --- | --- | --- |
| 1 | 序号 | 任意编号 |
| 2 | 省 | 可选，如「云南省」 |
| 3 | 市 | 可选，如「曲靖市」 |
| 4 | 区县 | 可选，如「麒麟区」（参与查询拼接与漂移比对） |
| 5 | 地址1 | 必填，主地址 |
| 6 | 地址2 | 选填，地址1异常时的备用地址 |
| 7-8 | GCJ-02 经度/纬度 | 正向编码输出 |
| 9-10 | WGS-84 经度/纬度 | 正向编码输出 |
| 11 | 标准地址 | 正向编码结果（漂移时追加「疑似漂移」） |

## 🔧 功能模块

| 模块 | 说明 |
| --- | --- |
| 单条查询 | 输入地址即时返回坐标、标准地址与精度 |
| 批量正向编码 | 整表处理，支持清洗/合并/去重/漂移检测，异常行黄色高亮 |
| 批量逆向编码 | 按坐标列批量反查地址 |
| 坐标转换 | GCJ-02 / WGS-84 / BD-09 三系互转 |
| POI 采集助手 | 关键字与周边搜索，结果导出 Excel |
| 在线更新 | 检测新版本并自动下载安装 |
